# Методичка: Описание параметров настроек UI

## Данные
- Размер буфера: Максимальное количество записей (свечей) в буфере Kline для хранения исторических данных. Влияет на объём данных, доступных для анализа и обучения модели.
- Интервал записи в CSV (сек): Периодичность сохранения предсказаний модели в CSV-файл (в секундах). Меньший интервал увеличивает частоту записи.
- Интервал переобучения (сек): Периодичность переобучения модели (в секундах). Определяет, как часто модель обновляется на новых данных.

## Модель
- Тип модели: Выбор алгоритма машинного обучения: Random Forest, XGBoost или LightGBM. Используется, если не включено тестирование всех моделей.
- Тестировать все модели: Если включено, обучаются и используются все три модели (Random Forest, XGBoost, LightGBM) для предсказаний. Результаты отображаются на графике.
- Максимальная глубина: Максимальная глубина деревьев в модели. Ограничивает сложность модели, снижая риск переобучения.
- Количество оценщиков: Число деревьев (или оценщиков) в ансамбле моделей. Большее значение увеличивает точность, но замедляет обучение.
- Период обучения (сек): Временное окно данных (в секундах), используемых для обучения модели. Определяет, сколько исторических данных берётся.
- Скорость обучения: Скорость обновления весов в градиентных моделях (XGBoost/LightGBM). Меньшее значение делает обучение более стабильным, но медленным.
- Подвыборка строк: Доля строк данных, используемых для обучения каждого дерева. Значения от 0 до 1, уменьшает переобучение.
- Подвыборка столбцов: Доля признаков, используемых для обучения каждого дерева. Значения от 0 до 1, снижает корреляцию между деревьями.
- Ранний стоп (раунды): Количество итераций без улучшения метрик, после которых обучение останавливается (для XGBoost/LightGBM).
- L1 регуляризация (alpha): Коэффициент L1-регуляризации для XGBoost/LightGBM. Уменьшает вес незначительных признаков.
- L2 регуляризация (lambda): Коэффициент L2-регуляризации для XGBoost/LightGBM. Сглаживает веса модели, снижая переобучение.
- Мин. сэмплов в листе: Минимальное количество сэмплов в листовом узле дерева (для Random Forest). Увеличивает устойчивость модели.
- Мин. сэмплов для сплита: Минимальное количество сэмплов для разбиения узла (для Random Forest). Повышает обобщающую способность.
- Использовать стакан: Включает/выключает использование признаков из стакана ордеров (bid/ask) в модели.
- Использовать scaler: Включает/выключает нормализацию признаков с помощью StandardScaler перед обучением модели.
- Число листьев (LightGBM): Максимальное количество листьев в дереве для LightGBM. Влияет на сложность модели.
